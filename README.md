ITD Extended Client

Расширенный клиент для сайта ИТД в формате UserScript.
Скрипт добавляет менеджер модулей, расширенные функции интерфейса и множество полезных модулей для улучшения опыта использования сайта.

📌 Описание

ITD Extended Client — это пользовательский скрипт для сайта ИТД (https://xn--d1ah4a.com/*).
Он внедряет в интерфейс расширенный менеджер модулей, который:

Позволяет включать/отключать дополнительные скрипты.

Загружать пользовательские скрипты (.js / .txt).

Автоматически подгружает выбранные модули и выполняет их на странице.

🚀 Возможности

Скрипт уже поставляется с рядом встроенных модулей:

✔ ITD Profile — клик по нику копирует ник, делает ссылки в BIO кликабельными.
✔ ITD Приближение — увеличить изображения колесиком мыши.
✔ ITD Счётчик — показывает количество загруженных постов в ленте.
✔ Pinned Profiles — закреп профилей и многое другое.
✔ ITD Фоны — кастомные фоны и GIF-фоны.
…и другие модули от сообщества.

🧠 Установка

Установите расширение для браузера, поддерживающее UserScripts (например: Tampermonkey, Violentmonkey).

Перейдите на страницу скрипта в GitHub.

Нажмите Raw → установите скрипт через ваш менеджер Userscript.

После установки скрипт автоматически активирует менеджер расширений на сайте ИТД.

⚙️ Как использовать

После установки:

Откройте сайт https://xn--d1ah4a.com/.

В левой панели появится новая кнопка для открытия менеджера расширений.

В менеджере можно:

Включать/выключать модули.

Загружать свои скрипты.

Просматривать описание каждого модуля.

🛠 Поддержка модулей
Встроенные модули

Все модули находятся в папке /modules/ и подгружаются по URL-адресам.
Каждый модуль содержит:

id — уникальный идентификатор

name — название модуля

auth — автор

desc — описание

url — ссылка на код модуля

🤝 Вклад в проект

Хотите добавить свои модули?

Форкайте репозиторий.

Добавляйте свои файлы скриптов (в формате .txt или .js) в папку modules.

Обновите список модулей в ITDEXT.user.js.

Оставьте описание и авторство.
