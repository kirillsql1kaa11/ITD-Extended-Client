## ✨ Что это?

**ITD Extended Client** — это пользовательский скрипт для сайта **ИТД**,  
который добавляет **менеджер модулей**, **улучшения интерфейса** и **дополнительные функции**,  
недоступные в стандартной версии сайта.

Скрипт работает напрямую в браузере и **не требует серверной части**.

---

## 🚀 Возможности

🔹 Модульная архитектура  
🔹 Включение / отключение функций в 1 клик  
🔹 Загрузка пользовательских модулей  
🔹 Улучшение UX / UI сайта  
🔹 Расширение функциональности профилей и ленты  

---

## 🧩 Встроенные модули

| Модуль | Описание |
|------|---------|
| **ITD Profile** | Клик по нику копирует имя, ссылки в BIO становятся кликабельными |
| **ITD Zoom** | Приближение изображений колесиком мыши |
| **ITD Counter** | Счётчик загруженных постов в ленте |
| **Pinned Profiles** | Закрепление профилей |
| **ITD Backgrounds** | Кастомные фоны и GIF-фоны |

> ⚠️ Список модулей постоянно расширяется
