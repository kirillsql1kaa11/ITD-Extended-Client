## ✨ Что это?

**ITD Extended Client** — это пользовательский скрипт (UserScript) для сайта **ИТД**,  
который расширяет стандартный функционал платформы и добавляет удобный  
**менеджер модулей** прямо в интерфейс сайта.

Скрипт работает полностью в браузере и не требует серверной части.

---

## 🚀 Возможности

- 🔹 Модульная архитектура  
- 🔹 Включение и отключение функций в один клик  
- 🔹 Поддержка пользовательских модулей  
- 🔹 Улучшение UX / UI  
- 🔹 Расширение возможностей профилей и ленты  

---

## 🧩 Встроенные модули

| Модуль | Описание |
|------|---------|
| **ITD Profile** | Копирование ника по клику, кликабельные ссылки в BIO |
| **ITD Zoom** | Приближение изображений колесиком мыши |
| **ITD Counter** | Счётчик загруженных постов |
| **Pinned Profiles** | Закрепление профилей |
| **ITD Backgrounds** | Кастомные фоны и GIF-фоны |

> ⚠️ Список модулей регулярно пополняется

## 🛠 Установка

### 1️⃣ Установите менеджер UserScript
Подойдут:
- Tampermonkey
- Violentmonkey

### 2️⃣ Установка скрипта

1. Откройте файл **ITDEXT.user.js**
2. Нажмите **Raw**
3. Подтвердите установку в менеджере скриптов

---

## ⚙️ Использование

1. Перейдите на сайт **ИТД**
2. В интерфейсе появится кнопка **ITD Extended**
3. Через меню можно:
   - Управлять модулями
   - Включать / выключать функции
   - Загружать пользовательские скрипты

## 🧠 Архитектура проекта
ITD-Extended-Client/
├── ITDEXT.user.js # основной userscript
├── modules/ # дополнительные модули
└── README.md


Каждый модуль содержит:
- `id` — уникальный идентификатор  
- `name` — название  
- `author` — автор  
- `description` — описание  
- `url` — ссылка на код
